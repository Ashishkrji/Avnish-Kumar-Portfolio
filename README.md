# Avnish Kumar Ray — Premium MBA Portfolio Website

A highly polished, responsive, and interactive personal portfolio website custom-tailored for **Avnish Kumar Ray**, an MBA student specializing in **Business Analytics & Finance** at CT Group of Institutions, Jalandhar, Punjab.

Developed with sleek typography, modern Tailwind CSS layout models, native high-performance scroll animations, and interactive functional integrations.

---

## 🚀 Live Features

### 🎓 1. Dynamic Alternating Education Timeline
- Highlights academic history including **MBA (Business Analytics & Finance)**, **Bachelor of Arts (Hindi)**, **Intermediate (Mathematics)**, and **Matriculation**.
- Features detailed, course-tailored curriculum descriptions and skill takeaways within premium responsive timeline cards.

### 📊 2. Technical Skills & Certifications Dashboard
- **Technical Proficiency**: Grouped, clean gradient skill meters highlighting core business analysis platforms (Advanced Excel, R, Python, Power BI) and valuation frameworks.
- **Verified Certificates**: Beautifully styled list of achievements featuring "Verified ✓" tags and smooth hover scaling effects.

### 💼 3. Work Experience Pane
- **Solitaire Infosys Internship**: A split dashboard presenting high-impact deliverables (Financial Reporting, Analytical Modeling, and Process Optimization) in a clean checklist format.
- **3D Personal Competencies Grid**: Hover-interactive cards showing key soft skills (Teamwork, Adaptability, Problem-Solving, Time Management).

### ✉️ 4. Advanced Dual-Submit Contact Form
- **Web3Forms API**: Submits lead data silently in the background for permanent email delivery.
- **WhatsApp Click-To-Chat API**: Launches pre-filled instant WhatsApp chat dynamically on button submit to ensure zero friction.
- Fully features active button loader states, disabling systems, and a beautiful success feedback banner.

### ⚡ 5. Additional UX Features
- **High-Performance Scroll Observer**: Zero-dependency `IntersectionObserver` system that animates elements as they enter the viewport.
- **Sleek Floating Scroll-To-Top Button**: Instantly and smoothly returns users to the header.

## 🛠️ Tech Stack & Integrations

- **Styling**: Tailwind CSS CDN, custom vanilla CSS tokens (Teal theme).
- **Interactivity**: [Alpine.js](https://alpinejs.dev/) (for state management, dual-submit loader, and scroll visibility).
- **Icons**: SVG Inline Paths.
- **Forms**: [Web3Forms](https://web3forms.com/) for background emails.
- **Contact**: WhatsApp Click-to-Chat protocol.
